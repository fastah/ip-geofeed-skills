# Contributing

This repository helps individual network operators check and tune their own
public RFC 8805 geofeeds.

Please open an issue for a reproducible analyzer, documentation, installation,
or Fastah MCP problem. Include the Skill, analyzer, and Analysis schema versions.
Do not attach a private feed, credentials, tokens, internal addresses, or other
sensitive network information. Use a small made-up example when one is needed.

Pull requests should stay within the same user job: local geofeed review,
privacy-limited Fastah place search, and explicit approval before a corrected
file is written. Changes for bulk processing, hosted publication, unrelated IP
data products, or service operations are out of scope.

The files in this repository are released under [Apache-2.0](LICENSE).
